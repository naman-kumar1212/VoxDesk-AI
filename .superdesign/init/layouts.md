# Layout Components

## Public Header
- File: `src/components/Navbar.jsx`
- Structure: Sticky header with backdrop blur, logo mark, navigation links (`How It Works`, `Features`, `Track Ticket`), and Primary CTA (`Report an issue`).

## Public Footer
- File: `src/components/Footer.jsx`
- Structure: Semantic 4-column footer with brand mark, platform links, legal/privacy badges, and admin portal gateway.

## Admin Layout Shell
- File: `src/components/admin/AdminLayout.jsx`
- Structure: Viewport-height `100dvh` shell with fixed left rail (`AdminSidebar.jsx`), sticky breadcrumb topbar (`AdminTopbar.jsx`), and isolated inner scroll container (`AdminMainContent.jsx`).
