# UI Primitives & Components

## 1. StatusBadge (`src/components/StatusBadge.jsx`)
Status indicators with calm semantic dots and Stripe support accents:
- Statuses: `open`, `in_progress`, `resolved`, `escalated`
- Priorities: `low`, `medium`, `high`, `urgent`

## 2. StatCard (`src/components/StatCard.jsx`)
Compact KPI metric cards with tabular numbers, subtle icons, and comparison indicators.

## 3. AudioWaveform (`src/components/AudioWaveform.jsx`)
Live Web Audio API `AnalyserNode` frequency spectrum visualizer sampling 16 frequency bands.

## 4. LoadingSkeleton (`src/components/LoadingSkeleton.jsx`)
Zero layout shift placeholder skeletons matching exact component dimensions.
